# Vaultex Wallet

A self‑custody crypto wallet for the desktop.

## Features

- **Self‑custody onboarding** — Welcome → *Create a new wallet* / *Import / Restore wallet*,
  with an encrypted keystore file (UTC / JSON, V3) and a password that stays on the device.
- **Desktop shell** — title bar, menu and a status bar with live block numbers, gas price
  and cloud sync state.
- **Portfolio, Send, Receive, Swap, Buy & Sell, Activity, NFTs, Settings** across 10 networks.
- **Transactions** show pending → confirmed with network confirmations, fees and hashes.
- **Signing** — sends, swaps and sales are confirmed by re‑entering the wallet password.
